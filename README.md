# Negocio al Día · versión de prueba

Prototipo de alta fidelidad de **Negocio al Día**, plataforma web para micronegocios de publicidad y confección que trabajan por encargo (pedidos, cotizaciones, cobros y proveedores en un solo lugar).

- Todos los datos son ficticios y se guardan solo en el navegador de quien la abre.
- Se entra con el botón *Ingresar* (dueño) o *Probar como empleado*.

Proyecto de práctica de Ingeniería de Software (Corporación Universitaria Iberoamericana).
